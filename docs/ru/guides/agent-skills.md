# Установка навыка для агента

Начиная с версии 0.6.0, `codex-platform` содержит необязательный автономный установщик навыка. Исходный текст навыка принадлежит библиотеке и находится в `codex_platform.agent_skills.resources`. Установщик копирует его в существующий проект по пути `.agents/skills/codex-platform/` и добавляет ограниченный блок со ссылкой в корневой `AGENTS.md`. Для обычного использования библиотеки навык устанавливать не нужно.

Запускайте команды в окружении Python, где установлен `codex-platform`:

```bash
python -m codex_platform.agent_skills install --project /path/to/project
python -m codex_platform.agent_skills status --project /path/to/project
python -m codex_platform.agent_skills update --project /path/to/project
python -m codex_platform.agent_skills delete --project /path/to/project
```

Параметр `--project` должен указывать на существующий каталог. После обновления пакета запустите `update`, чтобы обновить установленный навык. `status` возвращает код 0 только для актуальной установки с совпадающими версиями, хешами файлов и блоком `AGENTS.md`; отсутствие навыка или повреждение дают код 1.

Установщик хранит список управляемых файлов и их SHA-256 в `.agents/skills/codex-platform/.manifest.json`. Посторонний текст в `AGENTS.md` и чужие файлы в каталоге навыка сохраняются. При локальных правках или удалении управляемых файлов команды `update` и `delete` останавливаются, чтобы не уничтожить изменения. Сохраните копию изменённых файлов, перенесите свои правила в отдельный навык и восстановите исходные байты управляемых файлов из той же версии пакета перед повторной командой. Если повреждён маркер, сохраните копию `AGENTS.md` и восстановите ограниченный блок по документации установщика. Не меняйте хеши в манифесте ради принятия локальных правок. Коллизии путей, повреждённые маркеры и манифест, символические ссылки и точки повторной обработки Windows также приводят к отказу. При обычной ошибке записи установщик пытается откатить изменения; гарантий атомарности при сбое питания или одновременном запуске нет.

Управляемый блок состоит ровно из четырёх строк (с окончаниями строк проекта). Значение `separator` равно `0`, если перед блоком не понадобился дополнительный перевод строки, и `1`, если он понадобился:

```markdown
<!-- codex-platform:skill:start -->
<!-- codex-platform:skill:separator=0 -->
Use [codex-platform](.agents/skills/codex-platform/SKILL.md) for codex_platform work.
<!-- codex-platform:skill:end -->
```
